# Фронтенд

Сторінка користувача + адмінка. Контракт із бекендом — [API.md](API.md).

## Стек

Vite + vanilla JS (ES-модулі) + SCSS. Excel/CSV в адмінці розбирає SheetJS (`xlsx`). Без фреймворків.

## Структура

Усе лежить у `frontend/`, команди запускаються звідти.

```
index.html            — сторінка користувача (усі екрани в одному файлі)
admin/index.html      — адмінка
src/app/              — логіка сторінки користувача (екрани, i18n, історія показів, анімація неба)
src/admin/            — адмінка (вхід, список фраз, діалоги, імпорт)
src/shared/api/       — клієнт API: real.js (справжній бекенд) і mock/ (імітація контракту в localStorage)
src/shared/           — спільні константи (мови, категорії) і валідація
src/styles/           — SCSS: app/, admin/, abstracts/, base/
public/images/        — лого, око, favicon, OG-картинка
scripts/build-demo.js — демо-збірка для клієнта
```

## Запуск і збірка

| Команда | Що робить | API |
|---------|-----------|-----|
| `npm run dev` | Дев-сервер: `/` — сайт, `/admin/` — адмінка | Мок (`.env.development`) |
| `npm run build` | Прод-збірка в `dist/` | Справжній `/api` (`.env`) |
| `npm run build:demo` | Демо в `dist-demo/`, відкривається з диска (file://) | Мок (`.env.demo`) |

Мок-логін в адмінку: `admin` / `admin`. Мок-дані живуть лише в localStorage браузера.

**Робота з локальним бекендом:** створити `.env.development.local`:

```
VITE_API_MOCK=false
API_PROXY_TARGET=http://адреса-бекенду
```

Саме `.env.development.local`: `.env.development` має вищий пріоритет за `.env.local` і перебив би `VITE_API_MOCK`.
Не направляти `API_PROXY_TARGET` на прод — зміни в локальній адмінці підуть у прод-базу.

**Перед деплоєм:** заповнити `VITE_SITE_URL` у `.env` (потрібен для OG-картинки).

## Продуктові рішення

- Мови: `lv`, `en`, `ru`, користувач обирає вручну на першому екрані. Кнопки зміни мови після вибору немає.
- Одна фраза = один запис із трьома перекладами. Категорії бачить лише адмін, користувач отримує випадкову фразу з усіх.
- Випадкову фразу обирає бекенд.
- На всіх стаканчиках один QR. Повторне сканування протягом 20 хв показує те саме послання; ID останніх 100 показаних фраз зберігаються на пристрої і йдуть у `exclude`. Кнопки «інше послання» немає.
- Адмінка російською, один акаунт без ролей. Імпорт CSV/Excel розбирається на фронті.
- Фронт і бекенд на одному домені, без CORS.
