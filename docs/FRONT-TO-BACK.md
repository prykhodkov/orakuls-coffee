## F-003 · Типи в JSON і заголовок Authorization (PHP)
**Статус:** open
**Дата:** 2026-10-29
**Стосується:** усі відповіді API, авторизація адмінки, розгортання

Бекенд буде на PHP, хостинг, найімовірніше, GoDaddy (Apache, cPanel). Є кілька типових для PHP речей, через які фронт зламається, хоча формально відповідь «схожа» на контракт.

1. **Числа — числами.** `id`, `total`, `active`, `page`, `perPage`, `created`, `index`, значення в `byCategory` і `missing` мають бути JSON-числами (`42`), а не рядками (`"42"`). PDO з MySQL за замовчуванням повертає рядки — потрібні `PDO::ATTR_EMULATE_PREPARES => false` + `PDO::ATTR_STRINGIFY_FETCHES => false` або явне приведення `(int)`.
   _Наслідок, якщо ні:_ в адмінці не працюють «Изменить»/«Удалить» (фронт шукає фразу за числовим `id`), а `exclude` у `GET /api/message` порівнює ID некоректно.
2. **Булеві — булевими.** `isActive` — `true`/`false`, а не `1`/`0` чи `"1"`/`"0"` (TINYINT з MySQL). Приводити `(bool)`.
   _Наслідок, якщо ні:_ рядок `"0"` у JS істинний — приховані фрази показуються як «Показывается».
3. **Об'єкти — об'єктами, навіть порожні.** `text`, `byCategory`, `missing`, `fields` мають бути `{}`, а не `[]`. `json_encode([])` дає `[]` — для порожніх асоціативних масивів використовувати `(object)[]` або `JSON_FORCE_OBJECT` точково.
   Також для коректної кирилиці/латиської: `JSON_UNESCAPED_UNICODE` (не обов'язково, але читабельніше в логах).
4. **Заголовок `Authorization` має доходити до PHP.** На Apache з PHP у режимі CGI/FastCGI він часто зрізається. Перевірити й за потреби додати в `.htaccess`:
   ```apache
   RewriteEngine On
   RewriteCond %{HTTP:Authorization} .
   RewriteRule .* - [E=HTTP_AUTHORIZATION:%{HTTP:Authorization}]
   ```
   _Наслідок, якщо ні:_ усі `/api/admin/*` повертають `401`, адмінка після входу одразу викидає на форму логіну.
5. **Роздача фронта.** `/admin/` має віддавати `frontend/dist/admin/index.html` (на Apache працює `DirectoryIndex index.html`), а `/api/*` — іти в PHP. Правила `.htaccess` для `/api` не повинні перехоплювати статику.

Прошу врахувати з самого початку і відповісти, якщо щось із цього не підходить під вашу реалізацію.
