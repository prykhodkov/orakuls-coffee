# Бекенд

_Цей файл веде бекенд-розробник (і його агент). Фронт тут нічого не пише — питання до бекенда йдуть у [FRONT-TO-BACK.md](FRONT-TO-BACK.md)._

Код бекенда — у папці `backend/`. Контракт, який має реалізувати бекенд, — [API.md](API.md).

## Що потрібно заповнити

- Стек (мова, фреймворк, БД).
- Структура репозиторію.
- Як запустити локально (команди, змінні оточення, де задаються логін/пароль адміна).
- Як фронт може підключитися до локального бекенда (адреса для `API_PROXY_TARGET`).
- Розгортання: де живе, як віддається статика фронта (`dist/` на `/`, `dist/admin/` на `/admin/`).
- Прийняті рішення, які не видно з `API.md`.
