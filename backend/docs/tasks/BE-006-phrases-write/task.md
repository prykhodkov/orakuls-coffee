# BE-006 · Створення, оновлення, видалення фраз

| Поле | Значення |
|------|----------|
| Тип | Story |
| Пріоритет | High |
| Компонент | backend |
| Залежить від | BE-005 |
| Блокує | BE-007 |

## Опис

Як адмін, я хочу додавати нові фрази, редагувати наявні (текст, категорію, видимість) та видаляти непотрібні, щоб підтримувати базу послань актуальною.

Валідацію фрази виділити в окремий компонент: її використовує й імпорт (BE-007).

## Обсяг

- `POST /api/admin/phrases` → `201` + створений `Phrase`.
- `PUT /api/admin/phrases/{id}` → `200` + оновлений `Phrase` (повна заміна `category`, `text`, `isActive`).
- `DELETE /api/admin/phrases/{id}` → `204` без тіла.
- Валідація:
  - `category` — обов'язкове, одне з: `love`, `money`, `luck`, `work`, `travel`, `mood`;
  - `text` — об'єкт з ключами `lv`, `en`, `ru`; кожне значення — рядок (можна порожній); після trim — до 500 символів; хоча б одна мова непорожня;
  - `isActive` — необов'язкове boolean, за замовчуванням `true`.
- Текст зберігається trimmed, plain text, `\n` дозволені, HTML не інтерпретується і не змінюється.
- `createdAt` встановлюється при створенні й не змінюється; `updatedAt` — при кожному оновленні (UTC).
- Помилки валідації: `422 validation_error` з `fields`, ключі — шлях до поля (`category`, `text`, `text.lv`, `isActive`); значення — машинний код (`required`, `invalid`, `too_long`, `empty`).

## Acceptance criteria

- [ ] Без токена всі три ендпоінти → `401`.
- [ ] `POST` з валідним тілом → `201`, у відповіді `Phrase` з новим числовим `id`, `isActive: true` (якщо не передано), `createdAt = updatedAt`.
- [ ] Після `POST` фраза з'являється в `GET /api/admin/phrases` та `GET /api/admin/phrases/{id}`.
- [ ] `POST` без `category` або з невідомою категорією → `422`, `fields.category` заповнено.
- [ ] `POST` із `text`, де всі три мови порожні (чи лише пробіли) → `422`, `fields.text = "empty"`.
- [ ] `POST` із текстом 500 символів → `201`; 501 символ → `422`, `fields["text.lv"] = "too_long"` (лічильник у символах, а не байтах: рядок із 500 символів `š`/`я` проходить).
- [ ] Текст, що після trim вкладається в 500, але з пробілами навколо перевищує — проходить; збережений текст — trimmed.
- [ ] `text` не об'єкт, відсутній ключ мови, не рядкове значення → `422` з відповідним полем у `fields`.
- [ ] `isActive` не boolean (`"yes"`, `1`) → `422`, `fields.isActive`.
- [ ] Некоректний JSON → `400 bad_request`.
- [ ] Переноси рядків `\n` зберігаються і повертаються без змін; текст із `<script>` зберігається як є, без екранування/видалення.
- [ ] `PUT` повністю замінює `category`, `text`, `isActive`; `createdAt` не змінюється, `updatedAt` оновлюється; відповідь `200` містить оновлений `Phrase`.
- [ ] `PUT` неіснуючого `id` → `404`; невалідні дані → `422` і запис у БД не змінюється.
- [ ] `PUT` з `isActive: false` прибирає фразу з видачі `GET /api/message`; з `true` — повертає.
- [ ] Очищення перекладу (`text.en = ""`) через `PUT` → фраза зникає з видачі `/api/message` для `en`, але лишається для інших мов.
- [ ] `DELETE` існуючої → `204` з порожнім тілом; повторний `GET` цього `id` → `404`.
- [ ] `DELETE` неіснуючої → `404 not_found`.
- [ ] SQL-ін'єкції у полях не виконуються (prepared statements); спецсимволи та емодзі зберігаються без спотворень.
