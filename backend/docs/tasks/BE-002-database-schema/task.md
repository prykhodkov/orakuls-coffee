# BE-002 · Схема БД і міграції

| Поле | Значення |
|------|----------|
| Тип | Task |
| Пріоритет | High |
| Компонент | backend, database |
| Залежить від | BE-001 |
| Блокує | BE-003 … BE-008 |

## Опис

Спроєктувати і створити схему MySQL 5.7 для фраз і службових даних, а також механізм застосування міграцій, який працює на shared-хостингу (без CLI-доступу — як мінімум запуск через phpMyAdmin / SQL-файли).

## Обсяг

**Таблиця `phrases`:**

| Поле | Тип | Примітка |
|------|-----|----------|
| `id` | `INT UNSIGNED AUTO_INCREMENT` PK | |
| `category` | `VARCHAR(16)` або `ENUM('love','money','luck','work','travel','mood')` NOT NULL | коди з `API.md` |
| `text_lv`, `text_en`, `text_ru` | `VARCHAR(500) NOT NULL DEFAULT ''` | 500 **символів** (utf8mb4), порожній рядок = переклад відсутній |
| `is_active` | `TINYINT(1) NOT NULL DEFAULT 1` | |
| `created_at`, `updated_at` | `DATETIME NOT NULL` | зберігаються в UTC |

Індекси: за `category`, за `is_active`.

**Таблиця `login_attempts`** (для rate limit у BE-004): `ip`, `attempted_at`, індекс по `(ip, attempted_at)`.

**Кодування:** `utf8mb4`, колація `utf8mb4_unicode_ci`, рушій InnoDB.

**Міграції:** SQL-файли з нумерацією (`001_create_phrases.sql`…) + простий runner (PHP-скрипт) з таблицею `migrations`, ідемпотентний. Поряд — повний `schema.sql` для ручного імпорту через phpMyAdmin.

**Сід:** скрипт/файл для завантаження тестових фраз (кілька на категорію, у т.ч. з порожніми перекладами) для локальної розробки. У прод не потрапляє автоматично.

## Поза обсягом

Реальний контент 600 фраз (завантажує адмін через імпорт, BE-007).

## Acceptance criteria

- [ ] Міграції застосовуються на чистій MySQL 5.7 без помилок і не використовують синтаксис 8.0.
- [ ] Повторний запуск runner'а нічого не ламає (ідемпотентність) і не дублює дані.
- [ ] `schema.sql` дає ту саму схему, що й послідовність міграцій; його можна імпортувати через phpMyAdmin.
- [ ] Таблиці й текстові колонки мають `utf8mb4` / `utf8mb4_unicode_ci`; фраза з латиськими діакритиками, кирилицею та емодзі зберігається й читається без спотворень.
- [ ] Рядок завдовжки рівно 500 символів (у т.ч. з багатобайтовими) зберігається повністю; 501-й символ відхиляє валідація (BE-006), а не мовчки обрізає БД (strict mode).
- [ ] `category` не може мати значення поза довідником.
- [ ] Є індекси за `category` та `is_active`; `EXPLAIN` вибірки з BE-003 не робить повного перебору по неіндексованих умовах, окрім `RAND()`.
- [ ] Дати зберігаються в UTC; доступ з коду повертає їх у ISO 8601 (`…Z`).
- [ ] Сід-скрипт наповнює локальну БД тестовими даними і не запускається на проді без явного прапора.
- [ ] Порядок розгортання схеми на хостингу описано в `docs/BACKEND.md`.
