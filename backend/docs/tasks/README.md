# Задачі бекенда

Кожна задача — окрема папка в цій директорії з файлом `task.md` (формат як у Jira: тип, пріоритет, опис, обсяг, залежності, acceptance criteria).
Контракт — [../../../docs/API.md](../../../docs/API.md). Стек — PHP 8.4, MySQL 5.7 ([BACKEND.md](../../../docs/BACKEND.md)). Технічна документація — [../README.md](../README.md).

## Загальні вимоги до всіх задач

- Відповіді строго за `API.md`: числа — числами, `isActive` — булевим, `text`/`byCategory`/`missing`/`fields` — об'єктами навіть порожніми (див. F-003).
- Помилки — у єдиному форматі `{ "error": { "code", "message", "fields?" } }`.
- Лише можливості PHP 8.4 і MySQL 5.7 (без CTE, віконних функцій, `utf8mb4_0900_*`).
- Усі запити до БД — через prepared statements.
- Секрети (пароль адміна, ключ підпису токена, доступ до БД) — поза репозиторієм і поза `public_html`.
- Зміни контракту — тільки через обмінні файли в `docs/`.
