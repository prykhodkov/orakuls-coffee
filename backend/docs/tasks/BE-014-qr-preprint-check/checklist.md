# BE-014 · Чек-лист контрольного прогону на проді (після деплою)

Готується заздалегідь, виконується **один раз на фінальному домені перед передачею QR у друк**. Нижче `<домен>` — домен без `www` і без слеша (орієнтовно `orakulscoffee.com`). Адреса в QR: **`https://<домен>/?qr`**.

## Що вже перевірено без хостингу (2026-11-03)

На локальному Apache-контейнері (`docker-compose.hosting.yml`, `tests/hosting-check.php`) правила `.htaccess` дають:

| Вхід | Результат (локально) |
|------|----------------------|
| `http://<хост>/?qr` | `301` → `https://<хост>/?qr` |
| `http://<хост>/?qr=1&x=2` | `301` → `https://<хост>/?qr=1&x=2` (query зберігається повністю) |
| `http://www.<хост>/?qr` | `301` → `https://<хост>/?qr` (без `www`, `?qr` збережено) |
| `https://<хост>/?qr` (емулюється `X-Forwarded-Proto`) | `200` без редиректів |

Мутація (редирект із `?` у кінці цілі) валить обидві перевірки `?qr` — тест чутливий. Це доводить **правила**, а не поведінку хостингу (проксі, TLS, `www` у DNS, сертифікат для `www`): це перевіряється нижче.

## 0. Підготовка

- [ ] Домен підтверджено клієнтом; DNS `<домен>` і (бажано) `www.<домен>` вказують на хостинг; сертифікат HTTPS діє на `<домен>` (і на `www.<домен>`, якщо хтось набере його).
- [ ] BE-009 завершено: пакет розгорнуто, `tests/hosting-check.php https://<домен>` зелений.
- [ ] Фронт із підтримкою `?qr` і `POST /api/visit` (F-005) розгорнуто на `/`; адмінка з вкладкою «Статистика» — на `/admin/`.
- [ ] У `frontend` заповнено `VITE_SITE_URL` (для `og:image`).
- [ ] Записано стан статистики **до** прогону (адмінка → «Статистика» → «Сегодня»): `scans₀`, `visits₀`, `messages₀`. Тестові відкриття лишаться в статистиці назавжди (скинути нічим) — це очікувано, зафіксувати в записі про перевірку.

## 1. Редиректи не гублять `?qr` (з хоста, команди з контейнера php)

```
curl -sI "http://<домен>/?qr"             | grep -iE "^(HTTP|location)"      # очікується 301 → https://<домен>/?qr
curl -sI "http://www.<домен>/?qr"         | grep -iE "^(HTTP|location)"      # очікується 301 → https://<домен>/?qr
curl -sI "https://www.<домен>/?qr"        | grep -iE "^(HTTP|location)"      # очікується 301 → https://<домен>/?qr
curl -sI "https://<домен>/?qr"            | grep -iE "^HTTP"                 # очікується 200, без Location (остаточна адреса QR)
```

(або `tests/hosting-check.php https://<домен>` — перевіряє те саме.) Якщо `?qr` зникає — виправити `RewriteRule` у `public_html/.htaccess` (`backend/deploy/public_html/.htaccess`) і повторити.

- [ ] `http://<домен>/?qr` → `https://<домен>/?qr`
- [ ] `http://www.<домен>/?qr` → `https://<домен>/?qr`
- [ ] `https://www.<домен>/?qr` → `https://<домен>/?qr` (і відкривається без попередження про сертифікат)
- [ ] `https://<домен>/?qr` → `200` без редиректів

## 2. Контрольний прогін із телефоном і QR

Згенерувати пробний QR на `https://<домен>/?qr` (будь-який генератор; фінальний файл від дизайнера перевіряється окремо в п. 4).

1. [ ] Відсканувати QR телефоном → відкрилась сторінка вибору мови; в адресному рядку **`?qr` зник**. Адмінка («Статистика» → «Сегодня»): «Сканирования QR» **+1**, «Открытия сайта» **+1**.
2. [ ] Вибрати мову і отримати послання → «Выдано посланий» **+1**, потрібна мова **+1**.
3. [ ] Повторно відсканувати протягом 20 хв → «Сканирования QR» **+1**, «Открытия сайта» **+1**, «Выдано посланий» **без змін** (послання з пам'яті пристрою, до API не звертається).
4. [ ] Поділитися посланням («Поделиться»), відкрити отримане посилання → «Открытия сайта» **+1**, «Сканирования QR» **без змін** (посилання веде на `https://<домен>`, без `?qr`).
5. [ ] Відкрити сайт, набравши адресу вручну без `?qr` → «Открытия сайта» **+1**, «Сканирования QR» **без змін**.

Сканування, відкриття через поширене посилання і відкриття вручну **не змішуються** (кроки 1, 4, 5).

## 4. Фінальний файл QR і клієнт

- [ ] Клієнту передано адресу `https://<домен>/?qr` із поясненням «чому саме така» (`https`, без `www`, слеш, `?qr`; без скорочувачів посилань і без додаткових параметрів — дизайнер/друкарня не повинні її «покращувати»).
- [ ] Клієнт підтвердив, що саме цю адресу закодовано в QR.
- [ ] Із **фінального файлу** QR (екран/пробний відбиток) відскановано телефоном і пройдено крок 2.1.
- [ ] Передруковувати стаканчики не доведеться: адреса підтверджена письмово.
