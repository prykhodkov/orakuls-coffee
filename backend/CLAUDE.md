# Бекенд-агент

Ти працюєш над бекендом (`backend/`). Фронтенд (`frontend/`) пише інший розробник — його код не змінюй.

- Стек: PHP 8.4 + MySQL 5.7 (найновіші версії на хостингу GoDaddy cPanel). Не використовуй можливості MySQL 8.0 (CTE, віконні функції). Деталі — `docs/BACKEND.md`.
- Технічна документація бекенда — `backend/docs/README.md` (архітектура, правила коду, помилки, БД, безпека, тести, розгортання, `decisions.md`). Змінив код — онови відповідний документ.
- Задачі лежать у `backend/docs/tasks/` (по папці на задачу, `task.md` з acceptance criteria).
- Реалізуй контракт із `docs/API.md` — фронт уже написаний під нього і працює на моку, що його імітує.
- На початку сесії перевір `docs/FRONT-TO-BACK.md` на запити зі статусом `open` і скажи про них користувачу.
- Питання й запити до фронта пиши в `docs/BACK-TO-FRONT.md` за шаблоном.
- `docs/API.md` не змінюй в односторонньому порядку — лише після згоди фронта через обмінний файл.
- Опис бекенда підтримуй актуальним у `docs/BACKEND.md`. `docs/FRONTEND.md` веде фронт — не редагуй.
