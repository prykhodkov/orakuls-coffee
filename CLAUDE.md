# Orākuls Coffee

QR-код на стаканчику → користувач обирає мову → отримує випадкове послання.

Один проєкт, дві частини, кожну веде свій розробник зі своїм Claude-агентом:

```
frontend/  — сторінка користувача + адмінка (правила агента: frontend/CLAUDE.md)
backend/   — API (правила агента: backend/CLAUDE.md)
docs/      — спільна документація і канал спілкування між агентами
```

Почни з `docs/README.md`. Працюй лише у своїй частині — у чужу папку не пиши, запити до іншої сторони йдуть через обмінні файли в `docs/`.
